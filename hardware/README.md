# Hardware

Contains all of the PCB designs for this project. 

**Note:** `oscilloscope-adc-hat` contains the PCB files for our original and ultimately failed attempt to design our own custom adc hat for the Pi Zero2W using an ADS4195. Ultimately, issues with signal integrity were our downfall. We have included these files in case you decide to try to make this work again, but ultimately it was not included in our final design.
